## Featured projects

### [Robotic Bionic Hand](https://github.com/sg-gupta/robotic-bionic-hand)
A tendon-driven robotic hand that mirrors your hand in real time from a webcam, with no gloves or markers.
- Uses HaMeR 3D hand reconstruction, optimised from 3-4 s/frame to 6-7 FPS on a 4 GB RTX 3050 (MediaPipe boxes, async pipeline, fp16 inference)
- STM32 BluePill drives 11 servos over a custom serial protocol
- A MediaPipe-only backend runs the same firmware
- **Stack:** Python, PyTorch, MediaPipe, STM32, C/C++

### [UAV Builds](https://github.com/sg-gupta/uav-builds)
Quadcopter and fixed-wing builds from my work with Team Robolution.
- 500 mm Pixhawk quad with autonomous waypoint missions and RTL/failsafe
- 5" FPV drone and fixed-wing UAVs for the IIT Bombay aeromodeling competition
- 10" INAV surveillance drone (6S 9000 mAh, ~30 min flight unloaded, ~20 min with a 1 kg payload)
- **Stack:** Pixhawk, INAV, Mission Planner, ELRS

### [Line-Following Robot](https://github.com/sg-gupta/line-following-bot)
My first robotics project, which grew from a basic 3-sensor follower into a PID-controlled competition bot. **Runner-up, IIT Patna Celesta 2024.**
- Automatic sensor calibration at startup, 4-way intersection detection and a junction state machine
- **Stack:** Arduino Nano, TB6612FNG, N20 motors, C++

### [WiFi RC Car Kit](https://github.com/sg-gupta/wifi-rc-car)
A 2WD WiFi-controlled car kit designed to be built in a single college workshop session, which I used to run hands-on workshops.
- **Stack:** ESP8266, ultrasonic obstacle stop, C++

### [Micromouse](https://github.com/sg-gupta/Micromouse_all)
Development files and tests for my micromouse robots (work in progress).
